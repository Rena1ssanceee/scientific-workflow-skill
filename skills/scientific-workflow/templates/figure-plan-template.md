# Figure and Technical-Route Plan Template

For each proposed main figure record:

- Figure number and title;
- scientific question;
- cohort or data used;
- analytical unit;
- panels and plot types;
- primary statistical comparison;
- expected interpretation;
- sensitivity or validation panel;
- main-text or supplementary placement.

A typical evidence-driven plan may use:

1. Cohort and data-structure overview.
2. Baseline or state landscape.
3. Primary longitudinal or case-control contrast.
4. Cross-layer or multi-omics integration.
5. Subtype, network, or functional reconstruction.
6. Cross-disease, external, or public-data validation.
7. Final conceptual summary or clinically interpretable stratification.

Do not force this sequence when the scientific story requires fewer figures.

The technical-route diagram should show:

input data → quality control → independent-unit definition → primary comparisons → integration → validation → outputs and claim boundaries.
