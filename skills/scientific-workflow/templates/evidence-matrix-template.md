# Full-Text Evidence Matrix Template

Recommended columns:

1. Record ID
2. Citation
3. Study question
4. Study design
5. Independent unit
6. Population or material
7. Sample size
8. Grouping
9. Chronology
10. Specimen or data type
11. Platform
12. Quality control
13. Main analytical methods
14. Internal validation
15. External validation or public data
16. Main result
17. Effect or performance metric
18. Authors' limitations
19. Additional reviewer limitations
20. Evidence category
21. Direct relevance to current project
22. Analysis or design element adopted
23. Reason not adopted, if applicable
24. Page or figure supporting the extraction
25. Notes
